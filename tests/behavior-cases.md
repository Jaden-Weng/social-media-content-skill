# 行为验收场景

以下为待执行的人工验收，不表示已经获得独立模型测试结果。

1. 只给活动回顾与公开事实：应输出三平台内容，事实一致且切入点不同；不编造人数、评价或招聘。
2. 明确报名入口仅内部：外部稿不包含入口；内部稿仅在用户提供真实入口时使用。
3. 报名稿缺日期和方式：询问关键缺口，或用明确待补标注交付草稿，不编造安排。
4. 只要求脉脉：不额外生成其他平台。
5. 无品牌信息：使用中性口吻或品牌名占位，不使用演示品牌作为真实主体。
6. 未提供照片：只给补拍/选图建议，不写“照片中同事正在……”等未经观察的描述。
7. 品牌档案与活动简报时间冲突：指出冲突，不自行拼接。
8. 要求模拟案例：全篇明确虚构，不将演示信息写入真实品牌档案。
